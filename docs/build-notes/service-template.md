## 5. Requests for shared changes (not edited — I own none of these files)

- **R1 · `assets/css/emul/typography.css` — Scrolling Text divider size.** `.nst-divider{font-size:.5em}` (Custom Text Repeat Divider Size: Half) is relative to the element's own 17 px font, not to the Custom Font Size `--fs`, so the ✦ between the last word of a chunk and the first word of the next one renders at 8.5 px (the kit specimen `/_kit/` shows the same). Expected (as Salient): half / three-quarters of the text size. Proposed: `.nectar-scrolling-text[style*="--fs:"] .nst-divider{font-size:calc(var(--fs) * var(--nst-div,1))}` with `--nst-div:.5` / `.75` set by `data-divider-size`, plus the `--fs-m` variant ≤ 690 px. No page workaround (the markup equals the kit specimen).
- **R2 · `src/partials/gs-uzklausa.html`, `src/partials/gs-poraste.html` — data-salient on element roots.** The 19 `check.py` warnings per service page are: GS-Užklausa KV rows 2–4 + the form note (`p.nectar-responsive-text`), GS-Poraštė link-list `a.nectar-cta` items. Tag them (e.g. „Horizontal List Item (KV rows) → …“, „Button → Type: Text Reveal Wave · Display: Block“) and my pages go to 0 warnings.
- **R3 · `docs/build-notes/kit.md` §10 (guidance only).** An element with its own entrance animation inside an Inner Column with **Mask Reveal** waits for the mask (its lazy image and trigger start only once the clip opens) → ~2 s late. Suggest the note „don't nest Image/Icon entrance animations inside Mask Reveal columns — the mask is the entrance“.
- **R4 · `assets/css/sgp-custom.css` C-8 — Page Submenu on phones/tablets (review finding, not fixable page-side).** Native Salient < 1000 px hides the links behind a centred „Menu“ link (`.mobile-menu-link`) with an absolute vertical dropdown (element-page-submenu.css); the emulation (`emul/interactive.css` + emul.js) and all 11 pages show a horizontal scrolling strip instead, which production can only get with custom CSS. The S2 `data-salient` now declares this. Proposed C-8 addition (5 lines, keeps the demo behaviour in WordPress): `@media (max-width:999px){.page-submenu .mobile-menu-link{display:none}.page-submenu ul{position:static;display:flex!important;overflow-x:auto;white-space:nowrap;scrollbar-width:none}#ajax-content-wrap .page-submenu ul li{display:inline-block;margin:0 24px 0 0}.page-submenu ul li a{border:0;padding:16px 0}}` — or, if the lead prefers zero custom CSS here, make the emulation show the native „Menu“ toggle + dropdown instead (then drop the note from S2).
